TECELABS é uma experiência web interativa para apresentação de equipamentos industriais em 3D.

O projeto utiliza React, Three.js e React Three Fiber para renderização e interação com modelos 3D, com foco em visualização de produtos, responsividade e experiência do usuário.

Tecnologias:
- React
- Vite
- Three.js
- React Three Fiber
- React Three Drei
- JavaScript
- CSS
